# SacSak（タスクタイムラインアプリ）— CLAUDE.md

## 概要

タグライン：「サクッと置くだけ、今日の段取り。」

コンセプト：**Task（在庫）とPlacement（配置）を分離する**。タスクを一度登録しておけば、日々のタイムラインに繰り返しタップで配置できる。カレンダーアプリのように「作成＝時間確定」を1セットにしない。

## アーキテクチャ方針

- **サーバーレス・ローカル完結**。SwiftData のみ、バックエンド無し
- 外部カレンダー連携（Google Calendar等）は**意図的に非対応**。固定の一回性イベントはカレンダーアプリ側に委ねる、本アプリはルーティン/柔軟配置に専念
- Swift / SwiftUI / SwiftData

## 🎯 現在のスコープ：v0（MVP）のみ実装する

**以下だけを作る。それ以外は指示があるまで絶対に実装しない：**

- Task CRUD（名前・詳細メモ・所要時間のみ）
- タイムラインへのタップ配置（空きスロット判定、15分刻みスナップ、duration上書き）

**明示的に対象外（v1.1以降・指示があるまで着手禁止）：**

- 色タグ / プリセットカラー → モノトーンで進める
- オンボーディング
- 通知（開始15分前リマインド）
- テンプレ機能（Template / TemplateItem）
- 投げ銭IAP・サブスク・課金まわり全般
- ドラッグ&ドロップ（タップ配置のみ採用、D&Dは不採用が確定事項）
- カレンダーピッカーでの遠距離ジャンプ（横スクロールのみ）
- ウィジェット

判断基準：「無料/有料」ではなく「コアループの検証に必要か」。v0で崩れたら以降は全部無駄になるので、コア以外は一切乗せない。

## データモデル（SwiftData）

v0で必要なのは Task と Placement のみ。Template / TemplateItem はv0では作らない。

```swift
Task
- id: UUID
- name: String
- memo: String?
- durationMin: Int          // デフォルト所要時間
- createdAt: Date
- deletedAt: Date?          // 論理削除

Placement
- id: UUID
- task: Task                // リレーション
- date: Date                // 配置日
- startTime: Date
- durationMin: Int          // Task.durationMin の初期値をコピー、独立編集可
- createdAt: Date
```

## タイムライン操作ロジック（ここが実装の肝）

1. 表示は1時間刻みのRow、縦スクロール。日付切り替えは横スクロール（ページング）のみ
2. Rowタップ → その時間帯の**空きスロット**を提示（既存Placementと重複する区間は除外）
   - 空きスロット計算：その日の全Placementを時系列ソート→空き区間を算出
3. Task一覧から選択 → `Task.durationMin` がデフォルト表示 → そのまま確定 or 15/30/45/60分でクイック上書き
4. 開始時刻は15分刻みにスナップ
5. **境界値に注意**：Placementの所要時間が1時間Rowをまたぐ場合、ブロックの高さは時間軸に比例して複数Rowにまたがって描画する。「1タップ範囲＝1Row」と「ブロックの見た目＝時間軸比例配置」は別レイヤー
6. 同一Row内に複数Placementが同時に存在できる前提で設計（1時間1タスク制限は不採用）
7. 既存ブロックをタップ → 編集/削除

## 画面（v0で必要なのは実質2〜3画面）

- ホーム/タイムライン（コア）
- タスク一覧（コア）
- タスク編集（モーダル）

履歴・統計、設定、投げ銭画面はv0では不要。
