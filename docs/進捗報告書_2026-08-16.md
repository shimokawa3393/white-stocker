# SacSak（WhiteStocker）進捗報告書

## 1. 概要

## 4. デザイン改善の経緯

### 4.1 デザインシステム

「インターネット初期のHTMLみたいなデザイン」という指摘を起点に、その場しのぎの数値をやめてトークン化した：

- `Spacing`（余白）・`CornerRadius`（角丸）・`AppColor`（色階調）を`Design/DesignTokens.swift`に集約
- 共通カード背景`CardBackground`（塗り＋極細エッジ＋2層シャドウ）を全画面で使い回し、統一感を確保

### 4.2 直近の調整（2026-08-16時点）

- **配置ブロック間の隙間**：`PlacementBlockView`の高さを`blockGap`分切り詰め、上下均等に隙間を作成（開始位置はごくわずかにずれるが視覚的対称性を優先）
- **角丸・影を段階的に抑制**：ユーザーフィードバックを都度反映し、`CornerRadius.small`を7→3、`medium`を10→5まで縮小。影も2層とも不透明度・広がりを控えめに調整
- **row背景色を一段濃く**：`subtleFill`・`elevatedFillGradient`のトーンを見直し、視認性を確保
- **選択画面にchevronを追加**：「タップ→次へ進む」操作であることを示すヒントとして、時間選択・タスク選択の行末に`chevron.right`を追加。タスク一覧（タップ→編集）には付けず、操作の違いを視覚的に区別
- **タスク一覧・選択画面の文字サイズ調整**：タスク名を`.body`→`.title3`に拡大、時計アイコン＋所要時間を太字に

### 4.3 これまでに解決した主な不具合（再掲・要点のみ）

- Japanese IME入力時のテキスト消失（`TextField`→`TextEditor`に変更）
- 配置ブロックのタップ範囲バグ（`.offset()`をButton自身に適用する形に修正）
- 背景色の半透明による罫線透過バグ（2回発生、`UIColor`動的トレイトで不透明化して解決）
- 実機ビルドのプロビジョニングエラー（未使用のPush/iCloud entitlementsを削除）

## 5. 新機能：タスクの最終使用順ソート

- `TaskItem`に`lastUsedAt: Date`を追加し、タスク一覧・選択画面のソートキーを`createdAt`→`lastUsedAt`に変更（両画面で連動）
- 配置作成時（`SlotPickerSheet.createPlacement`）に`lastUsedAt`を更新
- **注意点**：SwiftDataの軽量マイグレーションはプロパティの**宣言時点でのデフォルト値**を要求するため、イニシャライザ内代入のみでは既存ストアとのスキーマ不一致で`ModelContainer`生成が失敗しクラッシュした。`var lastUsedAt: Date = Date.now`と宣言時にデフォルト値を持たせることで解決済み

## 6. スコープ・マネタイズに関する意思決定

| 施策 | 判断 | 理由（要点） |
|---|---|---|
| 投げ銭IAP | 見送り | 機能と無関係な支払いはコンバージョンが低く、動機付けとして弱い |
| リワード広告（投げ銭の代替） | 見送り | 同上、ローカル完結アプリの世界観とも合わない |
| サブスクリプション／有料機能全般 | 保留 | v0未リリースの段階で時期尚早。まず無料で使われるかを検証すべき |
| コピペ機能（配置の複製） | 将来的に無料実装を検討 | 実装コストが低く、既存のSlotFinder等を流用できる |
| テンプレ保存機能 | 将来的に有料化を検討（未確定） | 新規モデル・複数画面・一括重複判定が必要で実装コストが高い。「無料版は痒いところに手が届かない程度、追加の利便性機能を有料にする」という方針を検討中。v0の使用実態を見てから判断する前提の保留事項 |
