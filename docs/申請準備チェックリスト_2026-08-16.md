# SacSak App Store申請準備チェックリスト

作成日：2026-08-16

スクリーンショット撮影以外に、申請前に対応が必要な項目をまとめる。

## 現状確認結果

- `AppIcon.appiconset` は Xcode デフォルトの `Contents.json` のみで、**画像ファイルが1枚も設定されていない**。申請前に必ず対応が必要。

## 1. アプリ内・技術面（今すぐ着手できるもの）

| 項目 | 状況 | 対応 |
|---|---|---|
| **App Icon** | `AppIcon.appiconset`が空（画像未設定） | 1024×1024のアイコン画像を1枚作成してXcodeに設定すれば、iOS 17以降は自動でリサイズされる（universal 1枚 + dark/tinted variantはお好みで） |
| **Apple Developer Program登録** | 未確認 | 年会費$99の登録が必須。無料アカウントのままだとApp Store配布不可（実機ビルドはできてもストア提出はできない） |
| **配布用の証明書・プロビジョニングプロファイル** | 現状は開発用の自動生成のみ | Xcode Organizer経由のArchive→Distributeで自動生成されるので、Developer Program登録さえ済めば通常は手動作業不要 |
| **バージョン/ビルド番号** | `MARKETING_VERSION=1.0`設定済み | 申請時そのままでOK。以後の差し替え申請時はビルド番号を上げ忘れないよう注意 |
| **権限説明文(Info.plist)** | 通知・カメラ等の権限を一切使っていない実装なので追加のUsage Descriptionは不要と思われる | 念のため最終ビルドで警告が出ないか確認 |

## 2. App Store Connect側の入力項目

- **アプリ登録**：Bundle ID・SKU・プライマリ言語の設定
- **プライバシー「栄養成分表示」(App Privacy)**：ローカル完結でサーバー通信が一切ないアプリでも、この申告自体は必須。「データを収集しない」で正直に回答できるはずだが、回答フローは必要
- **プライバシーポリシーURL**：データ収集がなくても、Connect上は入力必須項目になっている。「データを収集しません」と明記した簡易ページをどこかに公開する必要がある（GitHub Pagesの静的ページ等で十分）
- **サポートURL**：問い合わせ先ページ or 単純なメールアドレスの記載でも可
- **説明文・キーワード・カテゴリ**：説明文の執筆、カテゴリは「仕事効率化(Productivity)」が妥当
- **年齢制限アンケート**：質問票への回答（暴力・成人向け要素等なしなのですぐ終わる）
- **価格設定**：無料（Free）

## 3. その他

- **「SacSak」の名称最終確認**：提出直前の空き状況再チェック（設計書の次アクションに既に記載）
- **TestFlightでの事前確認（推奨）**：本番相当のビルドで一度動作確認してから提出すると、審査リジェクトのリスクを減らせる
